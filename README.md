# Samarth Kajla - Portfolio Website

Welcome to the source code for my personal portfolio website! This project serves as a digital resume and a showcase of my skills, projects, and professional background as an **AI & Python Developer**.

## 🌟 Overview

This website is a responsive, modern HTML/CSS/JS portfolio designed to highlight my expertise in **Artificial Intelligence, Python**, and software development. It features a clean, sleek user interface with a glassmorphism design approach.

## 🚀 Features

- **Responsive Design**: Built to look great and function seamlessly on desktops, tablets, and mobile devices.
- **Glassmorphism UI**: Uses modern CSS properties for a clean and sleek aesthetic.
- **Dynamic Typing Effect**: An interactive hero section that highlights my core competencies.
- **Project Showcase**: A dedicated section to display my featured projects (e.g., 2048 Game, Crypto Intelligence Dashboard) with links to source code.
- **Skills Matrix**: A clear visual representation of my technical skills categorized by Core Technologies and Tools.
- **Contact Integration**: Easy-to-use links for direct communication via Email, LinkedIn, and GitHub.

## 🛠️ Technologies Used

- **HTML5**: For structural markup.
- **CSS3**: For styling, layout, animations, and responsive design (includes Custom properties and Flexbox/Grid).
- **JavaScript (Vanilla)**: For interactive elements, such as the typing effect, navigation toggles, and scroll animations.
- **Google Fonts**: Utilizing 'Inter' and 'Space Grotesk' for typography.
- **FontAwesome**: For scalable vector icons.

## 📂 Project Structure

- `index.html`: The main HTML document containing the structure of the webpage.
- `styles.css`: The stylesheet containing all styling rules, colors, animations, and media queries.
- `script.js`: The JavaScript file containing logic for interactivity and dynamic text.

## 💡 Key Sections

1. **Hero**: Introduction with dynamic typing and call-to-action buttons.
2. **About Me**: Brief bio detailing my background, language proficiency, and core strengths.
3. **Skills**: Categorized technical skills including Python, AI/ML, Data Structures, Pandas, Scikit-Learn, etc.
4. **Projects**: Detailed cards for my featured projects with descriptions, tech stacks, and GitHub links.
5. **Contact**: Links to my LinkedIn, GitHub, and a direct email outreach button.
